# Icon attribution

These mode pictograms are from the Department of Transport and Planning's
"Transport Pictograms" dataset, Victorian Government Open Data:

| File | Source file | Used for |
|---|---|---|
| train.png | PICTO_MODE_Train.png | Metropolitan train |
| tram.png | PICTO_MODE_Tram.png | Metropolitan tram |
| bus.png | PICTO_MODE_Bus.png | Metropolitan bus, Regional bus |
| regional_train.png | PICTO_MODE_RegionalTrain.png | Regional train |
| coach.png | PICTO_MODE_Coach.png | Regional coach |

PTV's pictogram set has no separate symbol for regional (as opposed to
metropolitan) bus services, so the generic "Bus" pictogram is reused for
both `Metropolitan bus` and `Regional bus`.
